#### Data for the 1024-bit computation

In this folder we have saved the logs and a few small data files from our 1024-bit computation.
The file `main-log.txt` has stdout from all of the computation. Note that some steps were run 2+ times,
if a bug was encountered and had to be fixed. The file `root-log.txt` has stdout from the final hybrid
root step.

We have also included the polynomial, the target, the initial descent split, and the final descent output.
All other files are too large to share; they are at least several terabytes in total. Anyone interested in
seeing the full data files (e.g. the matrix or relation files) will need to contact us.
